# 🧭 Comqueror 🏠✨

🔎 A minimal start page with DuckDuckGo search, quick links 🔗, and an about page 💡.

<a id="-preview-locally"></a>

## 🚀 Preview locally 💻

💡 Serve this directory with a static HTTP server, for example:

```sh
python -m http.server 8000
```

🌐 Open `http://localhost:8000` in your browser. 🔎 Enter a search and press Enter ⌨️ to open the results on DuckDuckGo.

<a id="️-project-files"></a>

## 🗂️ Project files 🧩

- 🏠 `index.html`: start page and quick links 🔗.
- 🔎 `script.js`: DuckDuckGo search interaction ⌨️.
- 🎨 `style.css` and `assets/`: presentation and images 🖼️.
- 📜 `about/index.html`: background and license information.
